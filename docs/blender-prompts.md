## 🤖 角色设定

### 标准建模助手角色

```
你是一名 Blender 智能建模助手，擅长将自然语言指令转化为精准的 Blender 操作（建模/材质/动画）。

## 技能
1. 基础几何体创建：立方体、球体、圆柱体、圆锥体等
2. 高级建模：布尔运算、表面细分、挤压、倒角、曲线建模
3. 参数化建模：支持精确尺寸输入
4. 材质分配：金属、塑料、橡胶、玻璃等工业材质
5. 基础光照设置

## 注意事项
- 所有尺寸默认使用米 (m) 为单位
- 精度保持到小数点后 3 位
- 复杂操作分步执行并确认
- 当指令模糊时主动询问
```

## 📐 初始建模

### 通用零件建模提示词

```
【建模任务】
创建一个 [零件名称]

【尺寸规格】
- 整体尺寸：[长 × 宽 × 高，例如：0.1m × 0.05m × 0.02m]
- 关键特征尺寸：[例如：孔径 0.01m，壁厚 0.002m]

【几何特征】
- 基础形状：[立方体/圆柱体/自定义]
- 特征：[孔/槽/凸台/倒角/圆角]

【精度要求】
- 尺寸公差：±0.001m
- 表面质量：[光滑/标准]

请分步创建模型，每步完成后确认是否符合预期。
```

### 圆柱形零件（如容器、盖子）

```
【建模任务】
创建一个圆柱形 [零件名称，如：塑料容器/盖子]

【尺寸规格】
- 外径：[例如：0.08m]
- 内径：[例如：0.07m]
- 高度：[例如：0.05m]
- 壁厚：[例如：0.002m]
- 底部厚度：[例如：0.003m]

【特征细节】
- 顶部：[开口/封闭/螺纹]
- 底部：[平底/凹底/凸缘]
- 边缘：[圆角/倒角/锋利]

【材料类型】
- [塑料/金属/其他]

请使用圆柱体创建基础形状，然后使用布尔运算或挤压创建内部空腔。
```

### 方形/矩形零件

```
【建模任务】
创建一个矩形 [零件名称，如：底座/外壳]

【尺寸规格】
- 外形尺寸：[长 × 宽 × 高]
- 内部空间：[长 × 宽 × 深]
- 壁厚：[数值]

【特征细节】
- 安装孔：[位置、数量、孔径]
- 加强筋：[位置、厚度]
- 卡扣/卡槽：[位置、尺寸]

请创建立方体基础，然后使用布尔运算创建内部空间和特征。
```

### 带螺纹的零件

```
【建模任务】
创建一个带螺纹的 [零件名称，如：瓶盖/螺母]

【尺寸规格】
- 主体尺寸：[直径 × 高度]
- 螺纹规格：[公称直径 × 螺距，如：M20×1.5]
- 螺纹长度：[数值]

【螺纹类型】
- [外螺纹/内螺纹]
- [三角形/梯形/方形]

请使用螺旋曲线或螺纹插件创建螺纹特征。
```

## 🔧 微调修改

### 尺寸调整

```
【修改任务】
修改 [物体名称] 的尺寸

【当前尺寸】
- [列出当前尺寸]

【目标尺寸】
- [列出目标尺寸]

【修改要求】
- 保持 [哪些特征] 不变
- 只修改 [哪些部分]

请确认修改方案后再执行。
```

### 添加特征

```
【修改任务】
在 [物体名称] 上添加 [特征名称，如：孔/槽/凸台]

【位置要求】
- 相对于 [参考面/参考点]
- 距离边缘 [数值]
- 中心位置：[坐标或相对位置]

【尺寸要求】
- [特征的详细尺寸]

【数量】
- [单个/多个，如多个请指定排列方式]

请先预览添加位置，确认后再执行布尔运算。
```

### 倒角和圆角

```
【修改任务】
为 [物体名称] 添加 [倒角/圆角]

【选择边缘】
- [指定哪些边缘，如：顶部边缘/所有外露边缘]

【尺寸】
- 倒角距离：[数值，如：0.002m]
- 或圆角半径：[数值]

【类型】
- [等距/可变/角度]

请高亮显示选中的边缘，确认后再执行倒角操作。
```

### 壁厚调整

```
【修改任务】
调整 [物体名称] 的壁厚

【当前壁厚】
- [数值]

【目标壁厚】
- [数值]

【修改方式】
- [向外加厚/向内减薄/保持外形不变]

请确认修改方式，确保不影响配合尺寸。
```

## 🎨 材质与渲染

### 塑料材质

```
【材质任务】
为 [物体名称] 添加塑料材质

【材质属性】
- 基础颜色：[RGB 值或颜色名称]
- 表面质感：[光滑/磨砂/纹理]
- 透明度：[透明/半透明/不透明]
- 折射率：[如 1.49 对于 ABS]

【塑料类型】
- [ABS/PP/PE/PC/其他]

【渲染设置】
- 渲染引擎：[Cycles/Eevee]
- 光照：[HDRI/三点布光]

请使用 Principled BSDF 节点创建材质。
```

### 金属材质

```
【材质任务】
为 [物体名称] 添加金属材质

【材质属性】
- 基础颜色：[RGB 值]
- 金属度：1.0
- 粗糙度：[0.1-0.5，数值越小越光滑]

【金属类型】
- [铝/钢/铜/黄铜/其他]

【表面处理】
- [抛光/拉丝/喷砂/阳极氧化]

请创建金属材质并设置合适的粗糙度。
```

### 多材质零件

```
【材质任务】
为 [物体名称] 分配多种材质

【材质分配】
- 主体：[材质类型和颜色]
- 特征 1：[材质类型和颜色]
- 特征 2：[材质类型和颜色]

【材质边界】
- 请确保材质边界清晰
- 无重叠或缝隙

请使用多材质槽 (Material Slots) 分配材质。
```

### 简单渲染设置

```
【渲染任务】
为 [物体名称] 设置渲染场景

【环境设置】
- 背景：[纯色/渐变/HDRI]
- 地面：[反射/阴影捕捉]

【光照设置】
- 主光：[位置、强度、色温]
- 补光：[位置、强度]
- 轮廓光：[可选]

【相机设置】
- 视角：[俯视/平视/仰视]
- 焦距：[35mm/50mm/85mm]
- 景深：[开启/关闭]

【输出设置】
- 分辨率：[1920×1080 或其他]
- 采样：[128/256/512]
- 格式：[PNG/JPEG]

请创建三点布光系统并设置相机角度。
```

## ✅ 意图确认检查清单

在 AI 完成建模后，使用以下检查清单确认模型是否符合意图：

### 尺寸检查
- [ ] 整体尺寸是否正确？
- [ ] 关键配合尺寸是否在公差范围内？
- [ ] 壁厚是否均匀（如设计要求）？
- [ ] 孔位和孔径是否正确？

### 几何特征检查
- [ ] 所有特征都已创建？
- [ ] 倒角/圆角尺寸是否正确？
- [ ] 布尔运算后无残留面或边？
- [ ] 表面细分后形状保持正确？

### 设计意图检查
- [ ] 模型是否可实现设计功能？
- [ ] 是否有干涉或碰撞？
- [ ] 是否考虑了制造工艺（如脱模斜度）？
- [ ] 是否与配合件匹配？

### 材质和渲染检查
- [ ] 材质类型是否正确？
- [ ] 颜色是否符合预期？
- [ ] 表面质感是否合适？
- [ ] 渲染效果是否清晰？

### 检查清单提示词

```
【模型检查】
请按照以下清单检查模型：

1. 尺寸验证
   - 测量整体尺寸：[列出关键尺寸]
   - 测量配合尺寸：[列出配合尺寸]

2. 几何验证
   - 检查所有特征是否存在
   - 检查边缘处理是否完成

3. 设计意图验证
   - 模型是否可实现 [具体功能]
   - 与 [配合件] 是否匹配

请逐一检查并报告结果，如有问题请指出具体位置。
```

## ❓ 常见问题

### 模型精度不够

**问题**：创建的模型尺寸不精确

**解决提示词**：
```
请使用精确数值创建几何体，不要使用目测或估算。
所有尺寸请精确到小数点后 3 位（毫米级精度）。
创建完成后请测量验证关键尺寸。
```

### 布尔运算失败

**问题**：布尔运算后模型出现破面或错误

**解决提示词**：
```
在执行布尔运算前，请：
1. 确保两个物体有足够重叠
2. 检查法线方向是否正确
3. 必要时先应用修改器

如布尔运算失败，请尝试：
- 增加网格细分
- 使用不同的布尔求解器
- 手动修复拓扑
```

### 材质显示不正确

**问题**：材质在视口中显示正常，渲染后颜色不同

**解决提示词**：
```
请确认：
1. 使用的是 Principled BSDF 材质
2. 视口显示模式设置为"渲染"
3. 颜色空间设置正确（sRGB/Linear）
4. 光照强度合适，不过曝
```

### 渲染噪点过多

**问题**：Cycles 渲染结果噪点太多

**解决提示词**：
```
请优化渲染设置：
1. 增加采样数至 [256/512/1024]
2. 启用去噪（Denoising）
3. 检查光照强度是否足够
4. 考虑使用焦散或环境光遮蔽
```

## 📌 使用建议

1. **复制粘贴**：将相关提示词模板复制到对话框中
2. **填充参数**：替换方括号 `[...]` 中的内容为实际值
3. **分步确认**：复杂建模任务分步进行，每步确认后再继续
4. **保存记录**：保存成功的提示词，形成个人知识库

## 🔄 持续改进

提示词不是一成不变的，建议：
- 记录每次建模的成功经验
- 优化效果不好的提示词
- 添加新的场景和模板
- 定期整理和分类
